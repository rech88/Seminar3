### Задание 2 Развернуть строку

Программа реалезует функцию, которая разворачивает заданную строку.

Формат входных данных
В первой строке содержится целое число 𝑁 — количество строк в файле (2 ⩽ 𝑁 ⩽ 1 000).
В каждой из следующих 𝑁 строк записана одна строка, которую нужно развернуть. Строка
состоит только из символов латинского алфавита, и её длина лежит в диапазоне от 1 до 100
включительно.

Формат выходных данных
Выводится 𝑁 развёрнутых строк.

### Пример
input.txt | output.txt
----------|-----------
4         |
C         | C
is        | si
cool      | looc
language  | egauganal
