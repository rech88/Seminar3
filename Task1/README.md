### Задание 1 распечатать время
Реалезована функция, которая распечатывает в выходной файл время.

Формат входных данных
В первой строке содержится целое число 𝑁 — количество времён в файле (2 ⩽ 𝑁 ⩽ 1 000).
В каждой из следующих 𝑁 строк описано время в формате трёх целых чисел: h, m, s.

Формат выходных данных
Выводится 𝑁 строк, по одной дате в строке, в формате HH:MM:SS (см. пример).

### Пример
input.txt | output.txt
----------|-----------
3         | 12:37:59
12 37 59  | 01:01:01
1 1 1     | 23:59:59
23 59 59  |
